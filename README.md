# openworld-mobile

刷题微信小程序示例，支持本地题库、单题判题、得分统计与重新开始。

## 目录结构

- `/app.js` 小程序入口
- `/app.json` 全局配置
- `/pages/index` 刷题页面
- `/utils/questions.js` 本地题库

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向仓库根目录：
   `/home/runner/work/openworld-mobile/openworld-mobile`
3. AppID 可选择测试号（`touristappid`）。
4. 编译后即可在首页进行刷题。
